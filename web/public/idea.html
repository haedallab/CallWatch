경영진은 말한 만큼 해내는가

CallWatch는 미국 상장사가 어닝콜과 보도자료에서 내놓은 숫자 약속(가이던스)을 몇 달 뒤 SEC에 제출된 실제 실적과 맞대어 채점하고, 회사마다 “가이던스 신뢰도”를 보여주는 서비스입니다.

프로토타입 열기 API 문서 (Swagger) GitHub

대상 사용자와 문제

투자자는 경영진의 전망을 듣고 주식을 사지만, 그 전망이 과거에 얼마나 지켜졌는지는 확인하기 어렵습니다.

누가 쓰나

  • 미국 주식을 직접 보유한 개인 투자자
  • 기업을 분석하는 금융 실무자·MBA 학생
  • 내 포트폴리오 회사들이 믿을 만한지 한눈에 보고 싶은 사람

무엇이 어렵나

  • 약속은 콜 음성·보도자료 문장에, 실적은 석 달 뒤 공시 숫자로 따로 나옴
  • 회사마다 회계연도가 달라 “FY26 Q2”가 언제인지부터 헷갈림
  • 무료 서비스는 컨센서스 대비 서프라이즈만 보여주고, 회사 자신의 약속과는 비교하지 않음

해결 질문: “이 회사는 말한 만큼 해내는가, 다음 가이던스를 얼마나 믿어야 하는가”를 숫자와 원문 근거로 답한다.

데이터 확보와 분석 방향

무료 공공 데이터인 SEC 공시만으로 약속과 실적을 모두 구하고, 분석 규칙은 공개해 누구나 다시 계산할 수 있게 합니다.

데이터출처쓰임
실적발표 보도자료SEC EDGAR 8-K (Item 2.02) 첨부 Ex-99Outlook 절의 가이던스 문장
어닝콜 원문회사 IR 사이트 공개 트랜스크립트콜에서 말한 가이던스
실제 실적SEC XBRL companyfacts API매출·영업이익·EPS·설비투자 등 분기 값
주가yfinance (실패 시 Stooq)발표일·결과일의 초과수익률
  1. 약속 찾기보도자료와 콜 원문에서 “미래 기간 + 지표 + 숫자(범위)” 문장을 뽑습니다.
  2. 기간 맞추기회사별 회계연도로 “FY26 Q2” 같은 표현을 실제 기간과 XBRL 값에 연결합니다.
  3. 채점범위 안·유리한 이탈은 이행, 불리한 이탈은 미이행. 사업부문·기준이 다른 항목은 참고로만 표시합니다.
  4. 신뢰도와 시장 반응신뢰도 = 100 × (0.7 × 이행률 + 0.3 × (1 − 미이행 강도)). 발표일 전후 초과수익률(CAR)도 함께 계산합니다.

AI 활용 계획

AI는 숫자를 만들지 않고, 긴 원문에서 약속 문장을 찾아 정리하는 일과 근거를 붙여 답하는 일만 맡습니다.

가이던스 추출 (Gemini API)

규칙 엔진이 먼저 문장을 거르고, Gemini가 지표·기간·범위를 JSON으로 정리합니다. 원문 문장을 그대로 인용하게 하고, 서버가 그 인용이 원문에 있는지·숫자가 맞는지 다시 확인한 것만 남깁니다.

근거 기반 질문·답변 (RAG)

“Citi의 올해 순이자이익 가이던스는?” 같은 질문에, 그 회사 공시·콜 원문에서 찾은 문단만 근거로 답하고 문장마다 [1] 출처를 붙입니다. 근거에 없으면 모른다고 답하고 투자 권유는 하지 않습니다.

API 키는 서버에만 두고, 같은 문서는 다시 호출하지 않도록 응답을 캐시해 비용을 줄입니다.

프로토타입 화면과 이용 흐름

회원가입 없이 첫 화면에서 바로 결과를 보고, 한 회사의 약속을 원문 문장까지 따라가는 흐름입니다.

  1. 주요 종목AAPL, MSFT, NVDA, GOOGL, TSLA, SPCX, C, LLY 8종목의 신뢰도와 성향을 한 화면에서 비교합니다.
  2. 종목 › 약속 장부한 회사의 가이던스를 발표일 순으로 보고, 이행·미이행·대기·참고로 걸러봅니다.
  3. 근거 열기항목을 누르면 원문 문장, 실제 SEC 값, 콜 다시 듣기 링크, 그날 주가 반응이 나옵니다.
  4. AI에게 묻기궁금한 점을 질문하면 출처가 붙은 답을 받습니다.
  5. 내 포트폴리오보유 종목을 붙여넣으면 비중을 반영한 포트폴리오 신뢰도를 계산합니다.

판정 규칙은 판정 방법 화면에 공개되어 있습니다. 첫 접속 때 서버가 깨어나는 데 30초쯤 걸릴 수 있습니다.
