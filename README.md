# CallWatch — 내 계좌의 어닝콜 가이던스 × SEC 공시 × 주가

사용자가 가입해 **자기 미국 주식 보유종목**을 넣으면(붙여넣기·CSV·검색, 운영자 계정은 토스증권 Open API), 각 회사 경영진이 실적발표·어닝콜에서 내놓은 **가이던스(전망)**를
그 전망이 가리키는 회계 기간의 **SEC EDGAR 10-Q/10-K(XBRL) 실적**과 맞추고(Align), 결과가 공개된 날의
**주가 반응**까지 보여주는 서비스입니다. KAIST 디지털금융MBA 「금융빅데이터분석실습」 팀 프로젝트.

| 계층 | 기술 | 배포 |
|---|---|---|
| 프론트엔드 | React 18 + Vite + TypeScript, TanStack Query, Recharts, cmdk | **Vercel** (`web/`) |
| 백엔드 | FastAPI (Swagger `/docs`), SSE 스트리밍 | **Render** (`backend/`, `render.yaml`) |
| 로그인 | Supabase Auth (Google · 이메일 링크), 서버는 JWT(JWKS) 검증 | Supabase |
| 데이터 | SQLite 기본 · `DATABASE_URL`로 Supabase PostgreSQL | Supabase |
| 외부 API | 토스증권 Open API(조회 전용) · SEC EDGAR · yfinance/Stooq · Gemini | — |

> 투자 권유가 아닙니다. 판정은 SEC XBRL(GAAP) 수치 기준이며, 토스증권 연동은 조회 전용으로 주문 API를 호출하지 않습니다.

## 0. 가입 없이 쓰는 구조

| 화면 | 누구나 (가입 없음) | 운영자 (`OWNER_KEY`) |
|---|---|---|
| **주요 종목** (첫 화면) | AAPL·MSFT·NVDA·GOOGL·TSLA·SPCX·C·LLY 신뢰도 순위·이행 지도·알림 | 같음 |
| 종목 상세·AI 질문 | ○ (AI 질문 하루 `QA_DAILY_LIMIT`회) | 제한 없음 |
| 내 포트폴리오 | 보유 종목 표 **붙여넣기·CSV·검색**, 이 브라우저에만 저장 | + **토스증권 동기화** |
| 새 종목 분석 | 주요 종목 밖은 브라우저·IP당 하루 `ANON_DAILY_ANALYSIS_LIMIT`회 | 제한 없음 |

- **주요 종목은 서버가 미리 분석**: 서버가 켜지면 백그라운드에서 `FEATURED_TICKERS`를 SEC 실데이터로 분석하고 약 하루마다 갱신합니다(실패하면 10분 뒤 재시도). 방문자는 기다리지 않고 결과를 봅니다.
- **공유 캐시**: 공시만으로 만든 분석 결과는 종목별로 한 번 계산해 모두가 같이 씁니다. ‘다시 분석’도 최근 결과가 있으면 재사용해 SEC 호출을 아낍니다.
- **브라우저별 저장**: 붙여넣은 보유 종목과 올린 어닝콜 원문은 브라우저 id(`X-Client-Id`)별로 따로 저장되어 다른 방문자에게 보이지 않습니다.
- **토스증권은 운영자만**: 토스증권 Open API는 계좌 주인에게 발급되고 받은 정보는 본인 투자 목적으로만 쓰도록 되어 있어, 서버 연결은 운영자 계좌에만 씁니다. 다른 방문자에게는 이유와 함께 붙여넣기를 안내합니다.
- **콜 바로 듣기**: 8-K 보도자료의 ‘컨퍼런스콜·웹캐스트’ 문단에서 주소를 자동으로 찾아 발표마다 연결하고, 없으면 회사 IR 페이지로 안내합니다. 운영자가 녹음 파일(mp3 등) 주소를 등록하면 가이던스 근거 패널에서 바로 재생됩니다.
- **은행주 지표**: Citigroup(C)처럼 마진 대신 순이자이익(NII)·비이자비용으로 가이던스를 주는 종목을 위해 두 지표를 추가했습니다.
- **로그인은 선택**: Supabase Auth 로그인 코드는 들어 있지만 기본은 꺼져 있습니다. `SUPABASE_URL` 등을 넣으면 Google·이메일 로그인이 켜져 다른 기기에서도 같은 목록을 볼 수 있습니다.

## 1. 토스증권 연동 (운영자 전용)

공식 토스증권 Open API(`https://openapi.tossinvest.com`)를 **서버에서만** 호출합니다.

| 단계 | 내용 |
|---|---|
| 키 발급 | 토스증권 PC 웹(WTS) 로그인 → 설정 → Open API → `client_id`, `client_secret` |
| 허용 IP | 같은 화면에서 **백엔드 서버의 공인 IP**를 등록 (미등록 시 403). 앱이 403을 받으면 서버 공인 IP를 찾아 안내 문구에 보여줍니다 |
| 서버 설정 | Render 환경변수 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`, `OWNER_KEY` (Toss 키가 있으면 운영자 키가 없을 때 동기화가 잠깁니다) |
| 호출 | `POST /oauth2/token`(client_credentials) → `GET /api/v1/accounts` → `GET /api/v1/holdings` (헤더 `X-Tossinvest-Account: accountSeq`) → `GET /api/v1/exchange-rate` |

구현 포인트 (`backend/app/services/toss.py`)
- 토큰은 클라이언트당 1개만 유효하고 재발급하면 이전 토큰이 무효화되므로 **서버에서 캐시**하고, 401이면 한 번만 재발급합니다.
- 금액은 문자열, 손익률은 소수비율(0.1179 = 11.79%)로 오므로 숫자로 변환하고, 미국 종목은 환율로 원화 환산해 **평가금액 기준 비중**을 계산합니다.
- 미국 종목만 SEC 분석 대상으로 표시하고, 국내 종목은 비중 표시에만 쓰며 화면에 제외 사유를 보여줍니다.
- 계좌번호는 가운데를 가려 반환하고, 실계좌 동기화는 운영자 키가 맞을 때만 됩니다(그 외 403). 동기화한 보유 종목은 운영자 브라우저의 포트폴리오에만 저장됩니다.

## 3. 분석 엔진 (참고: Sonith-Bingi/earnings-call-intelligence 대비)

- **가이던스 원천 자동 수집**: 8-K Item 2.02 보도자료(Ex-99.1)의 Outlook 섹션 + 업로드한 콜 원문
- **규칙 + LLM 교차검증**: AI 결과는 원문에 같은 문장이 있고 수치가 맞을 때만 채택(환각 방지)
- **회계 달력 정렬**: 52/53주·1월·6월 결산 처리, “fourth quarter”, “Q2 FY26”, “full year” 해석
- **XBRL 정량 판정**: Q4 = 연간 − 3개 분기, 현금흐름은 YTD 차감, 최초 보고값 사용, Non-GAAP은 참고로만
- **방향성 판정**: 매출·마진·EPS는 높을수록, 영업비용은 낮을수록 유리, CapEx는 중립
- **이벤트 스터디**: 가이던스 발표일과 결과 공개일 각각의 CAR(시장모형, SPY)
- **경영진 신뢰도** = 100 × (0.7 × 이행률 + 0.3 × (1 − 이탈 심도)), 성향(보수적/정확/공격적)

## 4. 실행

```bash
pip install -r requirements-dev.txt
cp .env.example .env              # SEC_USER_AGENT, (선택) GEMINI_API_KEY, TOSS_* 
./run.sh                          # API :8000/docs + React :5173
cd backend && pytest -q           # 테스트 32건 (공개 접근·브라우저별 분리·한도·운영자 전용 토스 포함)
```
서비스는 SEC 실데이터만 씁니다. 가상 기업 4곳(KAIA·NBLU·HNRT·ORBT)은 자동 테스트용 고정 데이터로만 남아 있고(`ALLOW_DEMO=1`일 때만 켜짐), 배포 서버에서는 꺼져 있습니다.

### 배포
1. **Supabase (DB만)**: 프로젝트 → Database → 비밀번호 재설정 → Connect에서 **Session pooler** URI 복사 (Render 무료 플랜은 IPv6 직접 연결 불가). 백엔드 테이블은 RLS로 공개 API에서 막혀 있습니다
2. **Render**: `render.yaml` 블루프린트 → `SEC_USER_AGENT`, `GEMINI_API_KEY`, `DATABASE_URL`, (운영자용) `TOSS_*` 입력. `OWNER_KEY`는 자동 생성되며 대시보드에서 확인. Toss를 쓰면 아웃바운드 공인 IP를 토스증권 허용 IP에 등록
3. **Vercel**: Root Directory `web`, Framework Vite, 환경변수 `VITE_API_URL=https://<api>.onrender.com` (`vercel.json`에 SPA 라우팅·보안 헤더 포함)
4. Render의 `CORS_ORIGINS`에 Vercel 주소 입력
5. 첫 배포 후 몇 분이면 주요 종목 분석이 채워집니다. 발표 10분 전 `/health`를 열어 무료 인스턴스를 깨워 두세요

## 6. 발표 시연 순서 (5분)
0. 상단 **발표 모드**로 문제·결과를 슬라이드로 설명(방향키) → Esc로 앱 복귀해 시연
1. 첫 화면 **주요 종목**: 신뢰도 순위(예: C·LLY) → 행 클릭해 근거로 이동
2. **내 포트폴리오** → 토스증권 앱 표 붙여넣기 → 국내 종목 제외 표시 확인 후 저장 (운영자는 **토스증권에서 가져오기** 3단계 마법사)
3. 분석 시작 → 오른쪽 아래 실시간 진행 → 포트폴리오 KPI·이행 지도
4. ‘지금 확인할 것’ 카드 클릭 → 해당 가이던스로 딥링크, `J`/`K`로 이동, `O`로 원문 드로어
5. 발표문 정렬 보기 → 강조 문장 ↔ 판정 카드
6. ⌘K → 티커 입력 이동, 금액 가리기, AI에게 묻기(출처 번호 클릭)
7. `/docs`에서 API 확인

## 7. 한계
- 국내 종목(DART)은 아직 분석하지 않습니다. 수치 전망을 보도자료에 싣지 않는 회사는 콜 원문이 필요합니다.
- 표 형식 Outlook, 세그먼트별 가이던스, ‘mid-single digits’ 같은 모호한 표현은 판정하지 않습니다.
- 토스증권 Open API는 허용 IP에서만 동작하므로, 서버 IP가 바뀌는 환경에서는 다시 등록해야 합니다.
- 초과수익률에는 같은 날 다른 뉴스의 영향도 섞여 있어 인과로 해석할 수 없습니다.
